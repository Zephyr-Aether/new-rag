## 概念速览

平台围绕一条主线：**把一次 Agent 运行做成可解释、可治理、可回滚的企业流程**。

- **运行（Run）**：一次由 LLM + 工具 + 知识库驱动的最小可观测单元。每条 Run 都有步骤时间线、模型选择、工具/检索调用、成本、错误原因，可重放（Replay）与对比（Compare）。
- **评测（Evaluation）**：黄金集 / 坏案例 / 对抗集 / 回归集。新版本发布前自动跑基准回归，通过率回退会**阻断发布**。
- **发布（Release）**：版本 → 契约检查 → 回归 → 灰度（Canary）→ 全量，随时回滚。
- **治理（Governance）**：RBAC 默认拒绝、工具+发布审批、审计导出、租户配额与预算、数据生命周期、密钥加密存储。

## 环境

- 仓库：`new-rag`（FastAPI 后端 + React 控制台，单体代码库）
- 默认开发：`SQLite + mock LLM`（零外部依赖）
- 官方部署：`docker compose`（PostgreSQL+pgvector / Redis / MinIO / 应用 / Caddy TLS）
- 接口文档：服务启动后可打开 `/docs`（FastAPI OpenAPI）
