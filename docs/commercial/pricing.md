# 商用套餐边界定义

> 目标：让「产品页报价 → 后台限额 → 代码配置 → 客户账单」四个口径对齐。本文定义**套餐维度**与**三档默认档位**，并给出每个维度在代码里的落地配置与强制状态。

## 1. 套餐维度（9 项）

| # | 维度 | 含义 | 代码落点 | 强制状态 |
|---|---|---|---|---|
| D1 | 租户数 | 独立隔离的业务租户（数据/审计/配置完全隔离） | `/tenants`；租户配额 `tenant_max_concurrent_runs` | ✅ 有隔离；**租户数量上限未接线** |
| D2 | 用户数 | 每个租户内的账号数 | `/users`；RBAC `/auth/me` | ✅ 有管理；**数量上限/并发登录未接线** |
| D3 | Agent 数 | 可被对话/运行调用的知识型 Agent（版本树） | `/agents/{id}/versions`；`/meta.agent_id` | ✅ 有版本生命周期；**Agent 数量上限未接线** |
| D4 | 运行次数 | 计费/限额的主单位 | `/agents/runs`；`budget_max_*` per run | ✅ 每次 run 有成本/预算；**月运行次数配额未接线** |
| D5 | Token | LLM 用量 | `/cost/usage`（runs/tokens/cost）、`llm_price_*_per_mtok` | ✅ 有计量与单价；**按套餐限 token 额未接线** |
| D6 | 存储 | 上传/对象/向量容量 | `max_upload_bytes`、`knowledge_shard_count`、MinIO | ✅ 有单文件上限；**总量配额未接线** |
| D7 | 连接器 | 可用工具/MCP/自定义工具/集成通道数 | `/tools`、`/mcp`、`/custom-tools`、`mcp_tool_allowlist` | ✅ 有注册与白名单；**按套餐计连接器数未接线** |
| D8 | 审计保留期 | 审计日志/事件的保存期限 | `/audit`、`/audit/export`、`data/sweep` | ✅ 有导出与清除；**自动保留期策略未接线** |
| D9 | SSO | 身份源接入 | OIDC `APP_OIDC_*`；SAML 🚧 | ✅ OIDC 可用；**SSO 是否开通未套餐化** |

> 结论：**计量与治理能力已就绪，套餐化"配额的强制"大多还差一层落地**（详见 §4 接线清单）。套餐卖的是体验与治理档位，不是改架构。

## 2. 三档默认套餐（草案）

| 档位 | 定位 | 商用要点 | 关键配置示例 |
|---|---|---|---|
| **基础版** | 试运行/小组 | 单租户、≤20 用户、1 个 Agent、每月 ≤1k 次运行、≤10GB 存储、≤3 个连接器、审计保留 30 天、无 SSO | 限流收紧、禁用发布灰度 |
| **专业版** | 业务部门 | ≤5 租户、≤100 用户、≤10 个 Agent、每月 ≤50k 次运行、≤200GB、全连接器、审计保留 180 天、OIDC SSO | 全功能 QA/灰度/回滚/成本报表 |
| **企业版** | 合规体系 | 不限租户/SSO（含 SAML 接入排期）、审计保留按需 + 合规导出、专属支持、SLA | 数据保留、专属容量规划 |

- 各档**能力差异优先于数量差异**：例如"灰度/回归门禁是否可用"比"多几个用户"更值得收费。
- 正式报价以销售定价文档为准，本表是**工程对齐口径**。

## 3. 报价 vs 配置对齐表（上线前必须一致）

| 报价项 | 产品页文案 | 后台限额 | 代码配置 |
|---|---|---|---|
| 租户数 | 「支持 N 租户/多租户」 | 租户创建上限 | `tenants` 配额项（待接线 D1） |
| 并发 | 「N 并发 Run」 | `tenant_max_concurrent_runs=20` | `APP_TENANT_MAX_CONCURRENT_RUNS` ✅ |
| 单 run 预算 | 「N 步 / M tokens / $C 上限」 | per-run 预算 | `APP_BUDGET_MAX_*` ✅ |
| 上传 | 「单文件 ≤50MB」 | 上传上限 | `APP_MAX_UPLOAD_BYTES` ✅ |
| 成本透明度 | 「按租户×日结算」 | `/cost/usage` | `cost_service.usage()` ✅ |

## 4. 套餐化接线清单（技术债，按交付排期）

| 任务 | 目标维度 | 说明 |
|---|---|---|
| 租户/用户/Agent/运行/存储的**配额表**与强制层 | D1 D2 D3 D4 D6 | 在 `settings`/策略层加配额维度，超限返回统一错误码 |
| 月度运行/token 配额与**超限阈值** | D4 D5 | 增量计费 + 软告警/硬阻断 |
| 审计**自动保留策略**（到期清理） | D8 | 对接 `data/sweep` 定时任务 |
| SSO/连接器**套餐开关** | D7 D9 | 按套餐启用 OIDC / 连接器白名单 |
| 仪表盘/账单页展示套餐用量 | D4 D5 D6 | 前端 `/cost` 扩展 |
